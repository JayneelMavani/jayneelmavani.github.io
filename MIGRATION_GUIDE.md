# Modern Developer Portfolio

This is a complete rebuild of the portfolio as a modern, full-featured Next.js application.

## What's New? 🎉

### ✨ Complete Redesign
- **Modern UI** with glass-morphism effects
- **Beautiful dark theme** with cyan accents
- **Responsive design** that works on all devices
- **Smooth animations** with GSAP

### 🎯 New Features
- **Admin Dashboard** - Manage all content from one place
- **Blog System** - Write and publish articles
- **Project Management** - Showcase your work
- **Skills Tracker** - Display your expertise with levels
- **Contact Form** - Get inquiries from visitors
- **Social Integration** - Connect all your social profiles

### 🛠️ Technology Stack
- **Next.js 14** - Latest React framework
- **React 18** - Modern UI library
- **Tailwind CSS** - Beautiful styling
- **GSAP** - Professional animations
- **TypeScript** - Type-safe development

### 📄 Pages
1. **Home** (`/`) - Hero section with featured projects
2. **About** (`/about`) - Your background and experience
3. **Projects** (`/projects`) - All your projects
4. **Blog** (`/blog`) - Your articles and posts
5. **Contact** (`/contact`) - Get in touch form
6. **Admin** (`/admin/dashboard`) - Manage everything

## Quick Start

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Open http://localhost:3000
```

1. Update your info in `components/HeroSection.tsx`
2. Add your projects via admin dashboard
3. Write blog posts in the dashboard
4. Update skills in `components/SkillsSection.tsx`
5. Deploy to Vercel or your hosting
